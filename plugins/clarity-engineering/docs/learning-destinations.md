# Clarity Engineering Learning Destinations

Record learning only after it passes the admission test: novel, reusable, and expensive to rediscover.

| Learning | Destination |
|---|---|
| Recurring codebase problem/fix | Existing `docs/solutions/` or repository equivalent |
| Durable architecture trade-off | Existing ADR location |
| Repository workflow rule | Active project instructions/setup |
| Cross-repository preference | Global memory when available |
| Temporary execution detail | No durable artifact; session state only if work must resume |

Prefer updating or deduplicating an existing artifact. Do not create a raw per-Build capture plus a second curated document.

An ADR is warranted only when the decision is hard to reverse, surprising without context, and based on a real trade-off.
